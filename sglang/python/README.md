# SGLang with SingProbe

This SGLang build serves trained SingProbe heads and exports per-token hidden
states from selected decoder layers. It supports DeepSeek-V4.1-Flash,
Ling-3.1-flash, Qwen3.8-Flash-Next, and GLM-5.3-Flash.

See the [token-probe quickstart](https://github.com/inclusionAI/SingProbe/blob/main/sglang/README.md#token-probe-inference)
for installation, server launch commands, and examples of reading probe scores
and saving hidden states.
